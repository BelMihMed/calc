# Калькулятор экономии от внедрения BitrixGPT

Интерактивный калькулятор экономического эффекта от внедрения ИИ **BitrixGPT** в Битрикс24.
Самодостаточный фронтенд (HTML + CSS + JS), **без бэкенда** — все расчёты в браузере.

## Возможности
- Сценарии, сгруппированные: «Сценарии в CRM», «ИИ-агенты», «Другие сценарии», «VibeCode».
- Липкая панель навигации с быстрыми переходами и раздельными итогами экономии ФОТ и дополнительного потенциала.
- Поля коэффициентов вводятся в процентах; мгновенный пересчёт, разделители разрядов, валидация.
- Верхний блок «Данные о компании» автозаполняет связанные поля сценариев, но не перетирает ручные правки в сценариях.
- У каждого блока и у итога — иконка «i» с понятным пояснением, как считается экономия.
- Итог: экономия ФОТ, минимальные затраты первого года и чистая экономия; потенциал/выручка показываются дополнительно и не входят в окупаемость.
- Экспорт результата в **PDF** с выбором формата внедрения (облако/коробка), тарифа Битрикс24 и названием компании.
- Перед печатью отчёт открывается в полноэкранном предпросмотре; из него можно сохранить PDF или отправить документ на печать.
- Тарифы и подписки хранятся в едином `PRICE_CONFIG` с датой актуальности цен.
- В PDF-отчёте есть CTA с ссылками и QR-кодами на инструкцию по подключению и форму заявки.
- У ряда блоков «Подробнее» открывает отдельный лендинг со сценариями (в новом окне).
- Состав сформированных отчётов и клики по «Подробнее» могут логироваться в Google Sheets через Apps Script (`LOG_ENDPOINT`).

## Структура репозитория
```
index.html                      ← калькулятор (это и есть сайт GitHub Pages)
.nojekyll                       ← отключает Jekyll
golos-bitrix24.html             ← лендинг: Голосовое управление Битрикс24

assistant-bitrix24.html         ← лендинг: Личный ассистент
zapis-bitrix24.html             ← лендинг: Агент онлайн-записи
documents-bitrix24.html         ← лендинг: Генерация документов
README.md
package.json                    ← команда npm test для проверки формул
.github/workflows/tests.yml      ← запуск тестов в GitHub Actions
docs/
  TZ.md                         ← техзадание: формулы, сценарии, эталонные примеры
build/
  build_landings.py             ← генератор лендингов (ассистент/запись/документы)
  build_landing_support.py      ← генератор лендинга поддержки
tests/
  formulas.test.mjs             ← тесты формул и эталонных сумм

```

> Важно: ссылки «Подробнее» в калькуляторе **относительные**, поэтому все 6 HTML-файлов
> (`index.html` + 5 лендингов) должны лежать **в корне репозитория**, рядом друг с другом.

## Публикация на GitHub Pages
1. Залейте содержимое этой папки в репозиторий (минимум — корневые `.html` и `.nojekyll`).
2. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = **main**, папка = **/ (root)**. Сохраните.
3. Через 1–2 минуты сайт будет на `https://<логин>.github.io/<репозиторий>/`

```html
<iframe src="https://<логин>.github.io/<репозиторий>/"
        style="width:100%;border:0;min-height:1600px"
        title="Калькулятор BitrixGPT" loading="lazy"></iframe>
```
`min-height` подберите под высоту контента.

## Пересборка лендингов (необязательно)
Скрипты берут за основу `golos-bitrix24.html` (общий шаблон стиля) и подставляют контент:
```bash
python3 build/build_landings.py         # -> assistant / zapis / documents
python3 build/build_landing_support.py  # -> podderzhka
```

## Проверка формул
Тесты читают реальный `index.html`, извлекают из него сценарии и проверяют:
- базовые константы и дефолтные суммы сценариев;
- суммирование дополнительных сегментов;
- валидацию сценария поддержки;
- защиту ручных правок от автозаполнения;
- единый датированный конфиг тарифов.

```bash
npm test
```

На GitHub эти же тесты запускаются автоматически через GitHub Actions при `push` и `pull_request` в `main`.

## Тарифы и цены
Все тарифы, подписки BitrixGPT и коробочные подписки описаны в `PRICE_CONFIG` внутри `index.html`.
Там же хранится `actualOn` — дата актуальности цен, которая выводится в модалке выбора тарифа и в PDF-отчёте.

При обновлении цен меняйте только `PRICE_CONFIG` и запускайте `npm test`. Тест проверяет, что старые дублирующие словари цен не вернулись.

## Отчёты и аналитика

Отчёт формируется в браузере: HTML отчёта записывается в iframe предпросмотра, после чего пользователь сохраняет PDF через системную печать.

Перед формированием отчёта пользователь выбирает:
- формат внедрения: облако или коробка;
- текущий тариф/редакцию;
- название компании.

Если задан `LOG_ENDPOINT`, калькулятор отправляет в Apps Script события:
- `report` — состав отчёта, выбранный тариф, данные компании и рассчитанные суммы;
- `landing` — клик по ссылке «Подробнее».

Если `LOG_ENDPOINT` пустой, аналитика выключена.

## Методика расчёта
Формулы, константы (налоговая нагрузка ×1,4; 176 рабочих часов; и т.д.) и эталонные примеры —
в [docs/TZ.md](docs/TZ.md). Цены подписки BitrixGPT приведены при оплате за год.
Расчёт носит оценочный характер.
